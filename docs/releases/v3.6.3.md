# SkillHub 3.6.3

## 集合编辑

- 在同一编辑器中调整整个集合或单个成员的调用方式、集合共同要求和成员文档。
- 修改先保留为草稿，点击保存后统一提交；保存前检查集合和成员版本，冲突时保留草稿。
- 共同要求保留各成员原有规则；批量保存失败时恢复修改前的文件与元数据。
- 改进集合编辑器的表单层次、成员导航、独立滚动和窄窗口布局，避免重复显示同一成员名称。

## 体检与窗口

- 关闭体检队列弹窗后，后续项目继续在后台检查；完成后提供查看结果入口。完全退出 SkillHub 会结束应用进程。
- 检查进行时可审阅已就绪的项目；显式暂停会在当前项目完成后停止后续检查，可重新继续。
- 简介翻译遇到响应截断时提高输出预算重试；仍失败时报告失败，保留重试入口。
- 窗口关闭后到达的旧加载或保存结果不会覆盖新打开的编辑器；关闭编辑器时保留未保存草稿。

## 分类与同步

- 分类读取、编辑和删除兼容顶层 `category` 与 `metadata.category`，保留其他元数据、注释和文档正文。
- 项目同步预览分别显示待移除的 Skill 数量与文件数量，并列出各 Skill 的文件数。
- 可恢复当前项目已保存的选择，尚未同步的选择变动不会直接修改项目文件。

## 验证

- 完整本地检查通过：183 项 Python 回归中 182 项通过、1 项因符号链接权限跳过；69 项前端测试及离线 Agent 评测通过。
- 合成数据界面检查覆盖集合与成员切换、调用方式选择、共同要求草稿、保存按钮状态、桌面和窄窗口布局。
- 构建产物发布到对应标签，构建信息记录实际提交和源码指纹。

## 下载与校验

- `SkillHub.exe`：Windows 便携程序。
- `SHA256SUMS.txt`：程序 SHA-256 校验值。
- `BUILD_INFO.json`：对应提交、源码指纹和 EXE 哈希。
